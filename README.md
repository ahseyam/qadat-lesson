# منصة الحصة الموحَّدة — ابتدائية قادة الأمة الأهلية (بنين · وطني)

منصةٌ خاصّةٌ بالمدرسة: جدولُ الحصص الموحَّدة، والتحضير، والرصد، والنتيجة
والاعتماد، ولوحةُ المدرسة وتقاريرُها — بهويةِ المدرسة وكليشتها وشعارها.

**المرحلتان:** المرحلة الأولية · المرحلة العليا.
**الإشرافُ التربوي:** خمسةُ نطاقات — اللغة العربية · الرياضيات والعلوم ·
اللغة الإنجليزية · الاجتماعيات والإسلاميات · المهارات الرقمية والفنية والبدنية.
**الأدوار:** معلمٌ قائمٌ بالحصة · معلمٌ زائر · مدير المدرسة · الوكيل التعليمي ·
المشرف التربوي المختص · مدير الإشراف التربوي.

## البناء
```
CLS_GENDER=m python3 _المولّد/qadat_platform.py "منصة الحصة الموحَّدة — قادة الأمة.html"
python3 _المولّد/qadat_guard.py        # ⛔ حارسُ الهوية — يمسح الشجرة كلَّها
```

⛔ **حارسُ الهوية** يُفشل البناءَ عند أي ذكرٍ لجهةٍ أخرى — اسماً أو شعاراً أو
كليشةً أو نطاقاً. وهو مُجرَّبٌ على تسرُّباتٍ مصنوعةٍ قصداً.

⚠️ والهويةُ **بيانات** لا شفرة: `هوية/هوية.json` و`_المولّد/qadatdata.py`.
